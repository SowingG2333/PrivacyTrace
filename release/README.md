# Release assets

`DATA_MANIFEST.json` and `SHA256SUMS` are generated by
`scripts/package_release_data.py`. The three archives named in those files are
stored under `release_assets/` using Git LFS. This keeps every review artifact
inside the repository boundary handled by Anonymous GitHub and avoids links to
the identifying source repository.

After a normal clone, run `git lfs pull` before using the downloader. Anonymous
GitHub's current stream implementation resolves LFS pointer files when serving
or packaging repository contents.
